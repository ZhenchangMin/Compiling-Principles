# 实验三：中间代码生成

闵振昌　241880334

## 1. 实现内容

在实验一、二的基础上，将 C-- 源程序翻译为三地址中间代码。完成必做内容，仅选择选做 3.2：支持一维数组参数和高维数组变量。

- 沿用词法、语法和语义分析模块，新增 `ir.c`、`ir.h`。语法树保存类型与符号信息，IR 使用双向链表组织，翻译成功后统一写入文件。
- 逻辑表达式采用短路跳转；函数调用先计算实参，再逆序生成 `ARG`，支持嵌套调用和递归。`read`、`write` 分别转换为 `READ`、`WRITE`。
- 数组连续存储，按“基地址 + 下标 × 元素宽度”逐维寻址，整数宽度为 4 字节。一维数组参数传递地址，函数内修改作用于原数组。
- 实现常量折叠、代数简化、冗余赋值和跳转消除；保留表达式副作用，并处理模拟器负数除法与 C 向零截断规则的差异。

## 2. 编译与运行

在 Linux/WSL 中，在实验目录执行：

```bash
cd Code
make
./parser input.cmm output.ir
```

中间代码每行一条，写入指定输出文件。错误沿用 `Error type A/B/N at Line L: ...` 格式；不支持的类型输出 `Cannot translate: ...`。发现错误时不改写 IR 文件。

## 3. 测试结果

严格编译通过。普通版本及内存检测版本均通过 150/150 项测试，覆盖手册样例、递归、短路逻辑、多维数组、数组传参和错误诊断；生成的 116 组合法 IR 全部通过所给原版 `irsim.pyc` 的检查与执行。
